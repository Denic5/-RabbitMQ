# VPN Bot Lite

Лёгкая переработка [mercurykd/vpnbot](https://github.com/mercurykd/vpnbot): VPN-сервер, которым полностью управляют из Telegram-бота.

| | vpnbot (оригинал) | VPN Bot Lite |
|---|---|---|
| Контейнеры | 12+ (nginx, php, xray, wg, ocserv, adguard, …) | **1** |
| Код бота | ~10 000 строк PHP в одном файле | ~1 400 строк Python (aiogram 3) |
| Протоколы | много, часть уже блокируется | **VLESS + Reality** и **Hysteria2** — актуальные и устойчивые к блокировкам |
| Домен / SSL | нужен для части функций | **не нужен** |
| Обновление Xray/Hysteria | вручную | **кнопкой в боте**, с проверкой и откатом |
| Обновление бота | вручную | **кнопкой в боте** |

## Возможности

- **Пользователи**: добавить (можно пачкой), включить/отключить, удалить, срок действия, лимит трафика, сброс трафика.
- **Автоотключение** по истечении срока или лимита — с уведомлением админу.
- **Подписки**: одна ссылка на пользователя для Hiddify, v2RayTun, Happ, v2rayN, Streisand — приложение само подтягивает ключи, трафик и дату окончания. QR-код в боте и веб-страница с инструкцией.
- **Статистика**: трафик каждого пользователя, CPU/RAM/диск/аптайм сервера, состояние ядер.
- **Обновления**: проверка новых версий Xray и Hysteria2 на GitHub, установка одной кнопкой, проверка конфига новой версией, откат на предыдущую.
- **Настройки из бота**: SNI для Reality, смена ключей, вкл/выкл Hysteria2, обфускация Salamander, блокировка рекламы, адрес сервера.
- **Бэкап**: файл базы присылается раз в сутки и по кнопке; восстановление — просто отправить файл боту.
- **Надёжность**: если ядро упало — бот перезапускает его сам; Docker перезапускает бота; BBR и UDP-буферы настраиваются при установке.

## Установка

Нужен VPS с Ubuntu 22.04/24.04 или Debian 11/12 (x86_64 или arm64), root-доступ.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. На сервере:

```bash
apt-get update && apt-get install -y git
git clone https://github.com/ProffeSOr24/solution-template.git /opt/vpnbot
cd /opt/vpnbot/vpnbot-lite
./vpn.sh install <ТОКЕН_БОТА> <ВАШ_TELEGRAM_ID>
```

Скрипт поставит Docker, настроит ядро и запустит бота. Через минуту бот пришлёт сообщение «запущен» — нажмите `/menu`.

> Если на сервере стоит старый vpnbot — сначала остановите его (`cd /root/vpnbot && docker compose down`), иначе порт 443 будет занят.

### Порты

| Порт | Что |
|---|---|
| 443/tcp | VLESS Reality |
| 443/udp | Hysteria2 |
| 2096/tcp | ссылки-подписки |

Меняются в `.env` (`XRAY_PORT`, `HY2_PORT`, `SUB_PORT`), затем `./vpn.sh restart`. Если у хостера есть свой фаервол — откройте эти порты там.

## Как пользоваться

`/menu` → **👥 Пользователи** → **➕ Добавить** → отправьте имя, например `ivan`, или `ivan 30 100` (30 дней, 100 ГБ). Можно несколько строк сразу.

В карточке пользователя → **🔗 Ключи и QR** — бот пришлёт QR-код и ссылку-подписку. Её нужно отправить человеку:

- **Android / iOS**: Hiddify, v2RayTun, Happ — «Добавить из буфера» или сканировать QR.
- **Windows**: Hiddify или v2rayN — «Добавить подписку».
- **macOS**: Hiddify, Streisand.

Если открыть ссылку-подписку в браузере, будет страница со статусом, QR-кодом и кнопкой «Копировать».

## Обновления

**⬆️ Обновления** в боте показывает текущие и последние версии:

- **Xray / Hysteria2** — кнопка «⬆️ …» скачивает релиз с GitHub, проверяет, что он запускается и принимает конфиг, и перезапускает ядро. Если что-то не так — «↩️ Откатить».
- **Бот** — кнопка «⬆️ Обновить бота»: сервер делает `git pull`, пересобирает контейнер и перезапускается; после этого бот напишет «Бот обновлён».

То же вручную на сервере: `./vpn.sh update`.

## Команды на сервере

```bash
./vpn.sh status    # состояние
./vpn.sh logs      # логи бота
./vpn.sh restart   # перезапуск
./vpn.sh update    # обновить бота
./vpn.sh stop      # остановить
```

Все данные (база пользователей, ключи, сертификаты, обновлённые ядра) лежат в `data/`. Чтобы переехать на другой сервер — установите бота там и отправьте ему файл бэкапа.

## Если не работает

- **Бот молчит** — `./vpn.sh logs`: проверьте `BOT_TOKEN` и `ADMIN_IDS` в `.env`. Бот отвечает только админам из `ADMIN_IDS`.
- **Клиент не подключается по Reality** — в боте **⚙️ Настройки → 🌐 SNI** попробуйте другой домен (`dl.google.com`, `www.samsung.com`, `www.apple.com`), затем обновите подписку в приложении.
- **Hysteria2 медленная или не работает** — у некоторых провайдеров режется UDP/QUIC: включите **Обфускация** в настройках или пользуйтесь Reality.
- **Ядро упало** — **📜 Логи** в боте покажут причину; **📊 Сервер → ♻️ Перезапуск ядер**.
- **В ключах неверный IP** — **⚙️ Настройки → 📍 Адрес сервера** (или `SERVER_HOST` в `.env`).

## Структура

```
vpnbot-lite/
├── app/
│   ├── main.py      запуск: бот, сервер подписок, фоновые задачи
│   ├── bot.py       меню и обработчики Telegram
│   ├── service.py   настройки, ссылки, применение конфигов, учёт трафика
│   ├── cores.py     Xray и Hysteria2: конфиги, процессы, обновления
│   ├── sub.py       HTTP-подписки
│   ├── db.py        SQLite
│   └── config.py    переменные окружения
├── Dockerfile
├── docker-compose.yml
├── vpn.sh           установка и обслуживание
└── .env.example
```
