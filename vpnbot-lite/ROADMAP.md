# План развития VPN Bot Lite

## Ближайшее
- [ ] **Импорт AmneziaWG из старого vpnbot** (`./vpn.sh import-awg`): ключ сервера, параметры маскировки (включая S3/S4/I1), подсеть, порт и все клиенты с ключами и именами — роутер (Keenetic) переподключается без изменений, маршруты сохраняются. Сначала проверка без применения, применение — при переезде.
- [ ] **AmneziaWG 2.0 для новых конфигов**: S3/S4 и сигнатурные пакеты I1–I5 (имитация QUIC/DNS) поверх Jc/S1/S2/H; переключатель для старых клиентов, которые понимают только 1.0.
- [ ] **Переезд со старого vpnbot**: остановить старый бот, роутер — на AmneziaWG нового, подписки — на собственный сертификат (`./vpn.sh https 443`), освободить 80/443/853.
- [ ] **`./vpn.sh doctor`** — одна команда собирает всё для диагностики (версии, порты, ядра, логи, сертификаты, время, место, память) без секретов.
- [ ] **Готовый образ** — собирать на GitHub, сервер только скачивает: обновление ~1 минута вместо 10–20 и без нагрузки на 1 ГБ.
- [ ] **Маршруты в подписке для Happ** — российские сайты и банки напрямую, заблокированное через VPN; список правится из бота, переключатель «всё через VPN».

## Идеи
- [ ] **Менеджер паролей (Vaultwarden)** — свой сервер Bitwarden: у каждого члена семьи свой аккаунт, общая семейная коллекция, автозаполнение на телефоне. Бот: ежедневная зашифрованная копия, приглашения, уведомления. Нужен порт 443 с нормальным сертификатом — после переезда.
- [ ] Hysteria2 с настоящим сертификатом (после переезда).
- [ ] Уведомления: ядро упало, диск/память, сертификат истекает, у пользователя кончается трафик или срок.
- [ ] Самообслуживание: пользователь по приглашению сам получает подписку, QR, инструкцию, видит остаток.
- [ ] Кто сейчас онлайн и через какой протокол.
- [ ] Скачивание видео/музыки по ссылке (YouTube, Instagram, TikTok, VK).
- [ ] Доступ к нейросетям через сервер (свой API-ключ), голосовые в текст.
- [ ] Удалённый доступ к компьютерам — свой сервер RustDesk вместо TeamViewer/AnyDesk.
- [ ] Запасной мессенджер — свой сервер Matrix + Element.
- [ ] «Это развод?» — проверка ссылок и сообщений для родственников.
- [ ] Одноразовые секреты, проверка пароля на утечки.
- [ ] Напоминания о платежах (сервер, подписки), учёт расходов, заметки.
- [ ] Несколько серверов в одном боте, каскад через российский сервер (против белых списков).

## Не получилось
- **MTProto-прокси** (mtg, затем telemt): у мобильного оператора приветствие Telegram до сервера не доходит целиком на любом порту (43002, 993, 853) и с любой маскировкой — режется IP сервера. Код оставлен, по умолчанию можно выключить.
- **Reality с чужим SNI** (microsoft.com, yandex.ru) — режется; работает без SNI и XHTTP.
